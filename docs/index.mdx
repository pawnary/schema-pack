Schema Pack is a collection of serialization tooling for TypeScript and
JavaScript — encoders/decoders, byte-level debugging, benchmarking, and test
utilities for binary formats.

## Packages

<Cards>
  <Card
    title='@schema-pack/message-pack'
    description='Incremental MessagePack encoder/decoder with a pluggable extension system.'
    href='/docs/message-pack'
  />
  <Card
    title='@schema-pack/debugger'
    description='Format-agnostic, byte-level debugger for binary serialization formats.'
    href='/docs/debugger'
  />
  <Card
    title='@schema-pack/benchmark'
    description='Benchmark suite for comparing serializer implementations across data types.'
    href='/docs/benchmark'
  />
  <Card
    title='@schema-pack/vitest'
    description='Vitest matchers for asserting on Uint8Array byte content.'
    href='/docs/vitest'
  />
</Cards>

Each package is installed and versioned independently — see its page for
installation and usage details.
