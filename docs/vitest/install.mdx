[Vitest](https://vitest.dev) matchers for asserting on the contents of a buffer,
handy when testing binary or serialization code byte by byte.

## Installation

```bash
pnpm add -D @schema-pack/vitest@next
```

## Requirements

- Vitest (declared as a runtime dependency, so it's installed automatically)

## Setup

Import it once from your Vitest setup file so the matchers get registered (via
`expect.extend`) before your tests run:

Import matchers in `vitest.setup.ts`:

```ts
import '@schema-pack/vitest';
```

Add your setup file in `vitest.config.ts`:

```ts
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    setupFiles: ['./vitest.setup.ts'],
  },
});
```

Importing `@schema-pack/vitest` from any file that's part of your TypeScript
program (such as your Vitest setup file) is enough for TypeScript to also pick
up the ambient `Matchers` type augmentation, so `expect(...)` recognizes the new
matchers. If your setup file happens to live outside that program, add the
package to your TypeScript types configuration array instead (`tsconfig.json`):

```json
{
  "compilerOptions": {
    "types": ["vitest", "@schema-pack/vitest"]
  }
}
```
