## What is MessagePack?

[MessagePack](https://github.com/msgpack/msgpack/blob/master/spec.md) is a
binary serialization format: the same data model as JSON (maps, arrays, strings,
numbers, booleans, `nil`), but encoded as bytes instead of text — smaller and
faster to parse.

## How it works

Every value starts with a header byte that identifies its type. Small, common
values — short strings, small integers, arrays/maps with few entries — pack
their length into that same byte. Larger values use explicit-length variants
instead (`str32`, `array32`, `map32`, ...).

For example, `{ a: 1, b: 2 }` encodes to these 7 bytes:

```
130 161 97 1 161 98 2
```

- `130` — fixmap, 2 pairs
- `161 97` — fixstr, `"a"`
- `1` — fixint, `1`
- `161 98` — fixstr, `"b"`
- `2` — fixint, `2`
