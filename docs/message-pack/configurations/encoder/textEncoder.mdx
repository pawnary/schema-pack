---
title: textEncoder
---

- **Type:** `MessagePackTextEncoder`
- **Default:** `DefaultTextEncoder`

Encoder used to turn strings into bytes. A `NodeTextEncoder` is also provided
for faster string encoding on Node.

---

Example:

```ts
import { EncoderBuffer, NodeTextEncoder } from '@schema-pack/message-pack';

const encoder = new EncoderBuffer({
  textEncoder: new NodeTextEncoder(),
});
```
